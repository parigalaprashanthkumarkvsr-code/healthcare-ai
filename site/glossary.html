A.1 · Foundations and Clinical Systems

AI in Healthcare
computational systems that learn from clinical data to support medical decisions.
Machine learning (ML)
algorithms that infer patterns from data rather than following hand-coded rules.
Deep learning
multi-layer neural networks that learn features from raw data such as pixels, waveforms, or text.
CDSS
clinical decision support system: software combining patient data and medical knowledge into point-of-care advice.
Knowledge base
the computable medical knowledge inside a CDSS: rules, drug tables, or learned model parameters.
Inference engine
the CDSS component that applies the knowledge base to a specific patient's data.
Five rights of CDS
right information, person, format, channel, and time for decision support.
Alert fatigue
desensitization caused by excessive low-value alerts.
MYCIN
the 1970s rule-based expert system for antibiotic selection; accurate but never deployed.
IDx-DR
the first FDA-authorized autonomous diagnostic AI (diabetic retinopathy, 2018).
Telemedicine
remote clinical care via telecommunications, synchronous or store-and-forward.
RPM
remote patient monitoring: device-streamed vitals with algorithmic escalation.
Ambient documentation
AI-generated visit notes drafted from the consultation audio.

A.2 · Data, Standards, and Coding

EHR
longitudinal, computable digital record of patient encounters, orders, results, and medications.
Computability
the property that data can be queried and processed algorithmically, not just read.
Copy-forward
copying prior note text forward, propagating stale information.
HL7 FHIR
modern web-style clinical data exchange standard built on discrete resources.
DICOM
the medical imaging data standard: pixels plus a rich metadata header.
PACS
picture archiving and communication system; the imaging archive.
FASTQ
raw sequencing reads with per-base quality scores.
VCF
variant call format: called genomic variants per patient.
ECG / EEG / PPG
heart electrical, brain electrical, and pulse waveform signals.
ICD-10-CM
diagnostic classification system (WHO standard, national clinical modification).
CPT
AMA-maintained terminology for procedures and services.
SNOMED CT / LOINC / RxNorm
terminologies for clinical terms, lab observations, and medications.
Code as proxy
using billing codes as ML labels despite their coding-practice bias.

A.3 · Preprocessing and Features

Data cleaning
detecting and correcting errors and inconsistencies so records reflect clinical reality.
Normalization
rescaling features to a bounded range (min–max).
Standardization
rescaling to zero mean and unit variance (z-score).
MCAR / MAR / MNAR
missingness mechanisms: unrelated, explained by observed data, or tied to the missing value itself.
Imputation
filling missing values with estimates (median, KNN, MICE).
MICE
multiple imputation by chained equations; the principled MAR method.
Missingness indicator
a binary feature recording that a value was absent.
Selection bias
a training sample differing systematically from the target population.
Feature engineering
constructing model inputs that encode clinical meaning.
Comorbidity index
a validated summary of disease burden (Charlson, Elixhauser).
Observation window
the time interval whose data is allowed into features.
Leakage
information in training features that would not be available at prediction time.
HRV
heart-rate variability features (RMSSD, SDNN) reflecting autonomic state.
Morphology features
shape descriptors of a waveform (intervals, amplitudes, band powers).
LASSO
L1-regularized regression performing embedded feature selection.
PCA
linear projection maximizing retained variance.
NER
named entity recognition: tagging clinical concepts in text.
Negation/assertion detection
deciding whether an extracted concept is present, absent, or uncertain.
UMLS
the Unified Medical Language System metathesaurus linking clinical vocabularies.
Auto-coding
NLP-driven assignment of billing/diagnosis codes from clinical text.

A.4 · Modeling and Evaluation

Supervised learning
learning from labeled examples to predict defined targets.
Unsupervised learning
discovering structure (clusters, anomalies) without labels.
Phenotyping
deriving patient subtypes from data.
Risk prediction
supervised prediction of a future clinical event.
Time-zero
the defined moment from which features are measured.
Calibration
agreement between predicted probabilities and observed frequencies.
Sensitivity / specificity
recall on positives / recall on negatives.
PPV / NPV
positive and negative predictive values; prevalence-dependent.
AUC-ROC / AUPRC
area under the ROC curve / precision-recall curve.
Base-rate trap
ROC-AUC flattering a model at low prevalence.
Operating point
the threshold chosen for deployment by clinical cost.
Class imbalance
positive prevalence far below 50%.
SMOTE
synthetic minority oversampling by interpolation.
Focal loss
loss down-weighting easy examples to focus on hard ones.
LIME
local surrogate explanation by perturbation.
SHAP / Shapley value
game-theoretic average marginal contribution per feature.
TreeSHAP
exact, fast SHAP for tree ensembles.
Grad-CAM
class-activation map showing where an imaging model looked.
CNN
convolutional neural network; learned local filters for images.
Transfer learning
reusing pretrained representations for a new task.
LSTM / GRU
gated recurrent architectures for sequences.
U-Net
encoder–decoder segmentation network with skip connections.
Dice coefficient
segmentation overlap metric: 2|A∩B|/(|A|+|B|).
External validation
evaluation on data from a different population or institution.
MIMIC-III/IV
de-identified critical-care benchmark datasets.

A.5 · Imaging, Signals, and Genomics

WSI
whole-slide imaging: gigapixel digital scan of a pathology slide.
Gleason grading
prostate cancer aggressiveness grading from tissue architecture.
CADe / CADx
computer-aided detection / diagnosis.
Segmentation
pixel- or voxel-level delineation of a structure.
Multi-modal fusion
combining imaging, labs, notes, and signals in one model.
Polygenic risk score (PRS)
weighted aggregate of common-variant genetic risk.
Pharmacogenomics
genotype-guided drug selection and dosing.
Precision oncology
therapy selection driven by a tumor's molecular profile.
Virtual screening
ML-predicted prioritization of compound libraries.
QSAR
quantitative structure–activity relationship: property prediction from molecular structure.
Drug repurposing
finding new uses for approved drugs (signature reversal, knowledge graphs).
CGM
continuous glucose monitoring.

A.6 · Ethics, Regulation, and Trust

Bioethical principles
autonomy, beneficence, non-maleficence, justice.
Accountability gap
diffusion of responsibility for AI-influenced harm.
Automation bias
over-trusting machine output and stopping independent checking.
Demographic parity / equalized odds / calibration within groups
canonical group-fairness definitions.
Fairness audit
documented, disaggregated evaluation shipped with a model.
SaMD
software as a medical device: software with a medical purpose, not part of a hardware device.
510(k) / De Novo / PMA
the FDA's main approval pathways.
PCCP
predetermined change control plan: pre-authorized protocol for model updates.
CE marking / MDR
the EU conformity regime for medical devices.
Intended use
the claim an authorization covers; the boundary of lawful deployment.
Local validation
re-evaluation of a model on the deploying institution's data.
Shadow mode
silent parallel running of a model before live use.
Data drift / concept drift
input-distribution shift / outcome-relationship shift.
Model card
standardized documentation of intended use, data, performance, and limitations.
Calibrated trust
trust matched to measured, local, per-subgroup reliability.
Federated learning / FedAvg
decentralized training / weighted averaging of local model updates.
Cross-silo / cross-device
federation across a few institutions / many unreliable endpoints.
Secure aggregation
protocol where the server sees only the sum of updates.
Differential privacy (ε)
bounded influence of any one patient, bought with noise.
PHI
protected health information; health data linked to identifiers.
BAA
business associate agreement with any vendor processing PHI.
Safe Harbor / Expert Determination
HIPAA's two de-identification standards.
Endpoint–claim match
the trial must test the specific claim being made.
Cluster randomization
randomizing by clinician or unit to avoid contamination in AI trials.
